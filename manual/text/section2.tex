\label{sec:hardware}

Table~\ref{tab:hardware} gives the machine the reported results were produced on. Only the graphics
card really matters: toxicity scoring runs on it, and on a processor alone that stage takes hours
instead of minutes. Memory is not a constraint because no stage loads the whole corpus at once.
Windows is not required either, though the paths here use backslashes.

Four pieces of software are needed: \textbf{Python 3.11.9}, \textbf{Visual Studio Code} for the
notebooks, \textbf{Node.js 22.20.0} for the website, and the \textbf{CUDA build of PyTorch
2.11.0+cu128}, which installs separately from the rest.

\textbf{The Python version is not a suggestion.} It must be 3.11. Version 3.13 is the current
default on most machines and PyTorch publishes no CUDA build for it, so the toxicity stage fails
there with a missing-module error that does not point at the version.

Table~\ref{tab:packages} lists every package the project imports directly. These are pinned in
\texttt{notebooks\textbackslash requirements.txt}, so they install with one command.
